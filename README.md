# Token Structory

Dépôt de référence pour conserver notre réflexion sur le token Structory, les hypothèses de financement et la répartition envisagée. Ce dépôt doit rester fidèle aux décisions et aux questions réellement discutées.

## Point de départ de notre conversation

- Étudier le lancement d'un token Structory librement échangeable.
- Examiner un pré-seed de **150 000 € ou 200 000 $** (deux pistes discutées, pas une décision arrêtée).
- Dans cette hypothèse de financement, envisager **50 000 € pour rémunérer Larose75**.
- Envisager que le solde serve à rémunérer les contributeurs, en tenant compte des jetons déjà attribués et de ceux qui resteraient à attribuer.
- Comprendre comment un token peut se lancer et trouver naturellement des échanges, sans supposer qu'un acheteur ou une contrepartie existe automatiquement.

## Ce qui n'est pas décidé

Aucune offre totale, allocation définitive, blockchain, adresse de contrat, date de lancement, cotation ou liquidité n'est confirmée dans ces notes. Les montants ci-dessus sont des pistes de discussion à préciser, pas des engagements.
